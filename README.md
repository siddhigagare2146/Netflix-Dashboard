# 🎬 Netflix Data Analysis Dashboard

## 📌 Project Overview

This project is an interactive **Netflix Data Analysis Dashboard** created using **Microsoft Power BI**. The dashboard analyzes Netflix movies and TV shows to provide meaningful insights into content, genres, ratings, countries, and release trends.

## 📊 Dashboard Preview

![Netflix Dashboard](dashboard.png)

## 🔍 Key Insights

- 📺 Total number of Netflix titles
- ⭐ Analysis of ratings across Netflix content
- 🎭 Genre-wise distribution of titles
- 🎬 Comparison between Movies and TV Shows
- 🌍 Top 10 countries by Movies and TV Shows
- 📅 Analysis of Netflix content by release year
- 📈 Identification of trends in Netflix's content library

## 🛠️ Tools & Technologies

- **Microsoft Power BI**
- **Power Query**
- **Data Cleaning & Transformation**
- **Data Visualization**

## 🎯 Project Objective

The main objective of this project is to analyze Netflix's content library and transform raw data into an interactive dashboard. The dashboard helps users understand patterns and trends in Netflix content based on genres, ratings, countries, content types, and release years.
